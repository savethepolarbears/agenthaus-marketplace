# Outscraper Data Scraping Skill

## Start here

Resolve source platform, query/location, fields, result limit and budget. Read the tool catalog and the relevant workflow, then request a bounded sample. Validate freshness, duplication and quality before expanding; report counts, provenance and costs separately.

Keep credentials in environment/vault references. Verify current tool schemas before calls; examples in references are procedural guidance, not live service proof. Preserve authorization, privacy, rate limits and bounded output. Do not load every reference by default. Respect source terms and privacy; do not combine or resell PII without consent. Anonymize reviewers where needed.

## Load only the reference needed

Read the relevant safety/security, limits and failure guidance before a write or batch. Select the tool or workflow reference for the current task; all original procedures and examples remain in these files.
