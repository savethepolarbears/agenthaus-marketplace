# Analyze Semantic Vocabulary

Use this command to identify the semantic vocabulary—the complete set of terms and concepts that search engines associate with your target keyword. Essential for creating topically comprehensive content.

## Usage

```
/textfocus:semantic "your keyword" [--lang en]
```

## Parameters

- **keyword** (required): The keyword to analyze semantic vocabulary for
- **--lang** (optional): Language code (default: en). Examples: en, de, fr, es, it, nl, pt, ru, zh, ja

## What You Get

### Semantic Terms
- **Core concepts**: Essential vocabulary search engines expect
- **Related entities**: Named entities and concepts mentioned together
- **LSI keywords**: Latent Semantic Indexing terms (semantic variations)
- **Synonyms**: Alternative terminology for the same concept
- **Technical terms**: Industry-specific vocabulary
- **Supporting topics**: Related subjects mentioned in top content

### Semantic Coverage Metrics
- **Term frequency**: How often terms appear in top-ranking content
- **Importance score**: Relevance of each term to main keyword
- **Co-occurrence patterns**: Terms that appear together
- **Topic associations**: Which topics frequently co-occur

### Topical Comprehensiveness
- **Coverage percentage**: How much of the semantic space your content covers
- **Gaps**: Missing terms that top competitors use
- **Opportunities**: Underutilized semantic terms you can leverage
- **Density analysis**: How concentrated semantic terms are in top content

## Semantic Vocabulary Categories

### Primary Concepts
Core ideas directly related to the main keyword. These should be prominent in your content.

Example for "Machine Learning":
- Artificial intelligence
- Deep learning
- Neural networks
- Supervised learning
- Unsupervised learning
- Algorithm

### Technical Terms
Industry-specific vocabulary that establishes expertise and topical authority.

Example for "Machine Learning":
- Training data
- Model optimization
- Backpropagation
- Classification
- Regression
- Feature extraction
- Overfitting

### Related Fields
Adjacent topics that frequently appear together in authoritative content.

Example for "Machine Learning":
- Data science
- Big data
- Statistics
- Computer science
- Python programming
- TensorFlow
- Scikit-learn

### User Intent Terms
Words that indicate different user search intents around the topic.

Example for "Machine Learning":
- "How to learn"
- "Best practices"
- "Real-world applications"
- "Tools and frameworks"
- "Tutorial"
- "Certification"

### Question Format Terms
Words that appear in question-based searches.

Example for "Machine Learning":
- What is
- How does
- Why use
- When to use
- Where to apply
- Which tool

## Using Semantic Vocabulary for Content

### Content Enrichment
1. **Identify gaps**: Which semantic terms are missing from your content?
2. **Add naturally**: Weave semantic terms into existing content
3. **Create sections**: Add subsections for important semantic concepts
4. **Improve depth**: Explain semantic terms in context
5. **Link concepts**: Show relationships between semantic terms

### Topic Clustering
1. **Group related terms**: Organize semantic vocabulary into categories
2. **Create pillar content**: Comprehensive guide covering all categories
3. **Cluster content**: Create detailed pages for each semantic subtopic
4. **Link strategically**: Connect cluster pages back to pillar
5. **Build authority**: Establish topical expertise across cluster

### Competitive Content Gap Analysis
1. **Analyze top competitors**: Get semantic vocabulary from their content
2. **Compare against yours**: Identify missing semantic terms
3. **Prioritize opportunities**: Focus on high-impact missing terms
4. **Create new content**: Address semantic gaps competitors ignore
5. **Differentiate**: Go deeper on semantic subtopics

## Semantic Coverage Examples

### Strong Coverage (85-100%)
Content includes:
- All core concepts
- Most technical terms
- Related fields well-represented
- Multiple user intent variations
- Comprehensive question addressing
- Deep semantic depth

Result: Better rankings, more organic traffic, higher engagement

### Moderate Coverage (60-85%)
Content includes:
- Most core concepts
- Some technical terms
- Few related field connections
- Basic user intent coverage
- Limited question addressing
- Surface-level depth

Result: Decent rankings, but missing opportunities for improvement

### Weak Coverage (< 60%)
Content missing:
- Some core concepts
- Few technical terms
- Limited related field context
- Narrow user intent coverage
- Minimal question addressing
- Shallow treatment of topics

Result: Lower rankings, less traffic, missed opportunities

## Implementation Workflow

### Phase 1: Research
1. Analyze semantic vocabulary
2. Identify top 10-15 core semantic terms
3. Categorize by importance and frequency
4. Compare against competitor content
5. Identify semantic gaps

### Phase 2: Planning
1. Create content outline with semantic terms
2. Determine which terms need dedicated sections
3. Plan subsection structure
4. Design internal linking strategy
5. Identify supporting content needs

### Phase 3: Content Creation
1. Write comprehensive content covering all semantic categories
2. Naturally incorporate semantic terms
3. Explain relationships between concepts
4. Include user intent variations
5. Answer question-format queries

### Phase 4: Optimization
1. Ensure semantic term distribution
2. Add internal links to semantic subtopics
3. Include schema markup for concepts
4. Update internal linking strategy
5. Refresh with new semantic insights

### Phase 5: Measurement
1. Re-analyze semantic coverage (should reach 80%+)
2. Monitor keyword rankings (expect improvement)
3. Track organic traffic growth
4. Measure engagement metrics
5. Plan additional content based on gaps

## Tips for Semantic SEO

**Avoid Keyword Stuffing**
- Incorporate semantic terms naturally
- Maintain readability for human users
- Use variations and synonyms
- Don't force unnatural language

**Show Expertise**
- Use technical terminology correctly
- Explain complex concepts clearly
- Cite authoritative sources
- Demonstrate deep knowledge

**Answer User Intent**
- Address multiple search intents
- Include "how-to" and "best practices"
- Cover comparisons and alternatives
- Provide actionable advice

**Build Topic Authority**
- Create comprehensive content
- Link related semantic topics
- Build content clusters
- Maintain consistent messaging

**Monitor and Update**
- Re-analyze semantic vocabulary periodically
- Identify emerging terms
- Update content with new concepts
- Maintain competitive advantage
