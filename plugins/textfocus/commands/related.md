# Find Related Keywords

Use this command to discover semantically related keywords, search variations, and suggested keyword clusters for comprehensive content strategy.

## Usage

```
/textfocus:related "your keyword" [--lang en]
```

## Parameters

- **keyword** (required): The seed keyword to find related terms for
- **--lang** (optional): Language code (default: en). Examples: en, de, fr, es, it, nl, pt, ru, zh, ja

## What You Get

### Related Keywords
- **Synonyms**: Alternative ways people search for the same concept
- **Variants**: Plural, singular, and structural variations
- **Question-based**: "How to", "What is", "Why", "Best" format queries
- **Modifiers**: Keywords with additional qualifiers (e.g., "free", "best", "cheap")

### Search Suggestions
- **Auto-complete suggestions**: Popular searches Google/Bing suggest
- **People also ask**: Common questions related to your topic
- **Related searches**: What people search for after your keyword

### Keyword Clusters
- **Topic groupings**: Related terms that form natural content clusters
- **Content gaps**: Keywords showing what content is needed
- **Long-tail opportunities**: Specific variations with lower competition

## Using Related Keywords for Content Strategy

### Topic Cluster Planning
1. Start with pillar keyword (broad topic)
2. Get related keywords to identify cluster topics
3. Create content hub with pillar page and cluster content
4. Interlink with strategic anchor text

### Content Gap Analysis
1. Research competitor keywords
2. Get related keywords for your target
3. Compare lists to find gaps
4. Create content for missing topics
5. Build internal linking strategy

### Question-Based Content
1. Find "how to" and question format keywords
2. Create FAQ pages or detailed guides
3. Optimize for Featured Snippets
4. Answer user intent at every stage

## Tips

- **Start with seed keyword**: Choose your main topic keyword
- **Analyze competitor keywords**: See what keywords competitors target
- **Group by search intent**: Organize keywords by informational/commercial/navigational
- **Prioritize by opportunity**: Volume + difficulty + CPC combination
- **Build siloes**: Create topically related content clusters
- **Plan internal linking**: Link cluster content back to pillar
