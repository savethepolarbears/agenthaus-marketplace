# Encharge Marketing Automation Skill

## Start here

Resolve the exact account and intended people, tags, segment or email. Inspect current records before choosing a workflow. Preview recipient counts and mutations; confirm send/delete scope before execution and read back changed records.

Keep credentials in environment/vault references. Verify current tool schemas before calls; examples in references are procedural guidance, not live service proof. Preserve authorization, privacy, rate limits and bounded output. Do not load every reference by default. Keep contact data within the authorized account; respect consent, unsubscribe handling and retention. Do not put PII in logs.

## Load only the reference needed

Read the relevant safety/security, limits and failure guidance before a write or batch. Select the tool or workflow reference for the current task; all original procedures and examples remain in these files.
