# SEO Content Suite

A meta-plugin that combines four specialized tools into a unified SEO content production pipeline.

## Included Tools

| Tool | Purpose | MCP Tools |
|------|---------|-----------|
| **TextFocus** | Keyword metrics, semantic analysis | 5 tools |
| **NeuronWriter** | Content analysis, scoring, publishing | 7 tools |
| **MarkupGo** | Image/PDF generation, social assets | 16 tools |
| **Outscraper** | Market research, reviews, enrichment | 28 tools |

## Installation

```bash
/plugin install seo-content-suite
```

## Environment Variables

```bash
TEXTFOCUS_API_KEY=your_textfocus_key
NEURONWRITER_API_KEY=your_neuronwriter_key
MARKUPGO_API_KEY=your_markupgo_key
OUTSCRAPER_API_KEY=your_outscraper_key  # optional
```

You don't need all four keys — configure what you have and the pipeline adapts.

## Pipeline Workflows

1. **Full Article Pipeline** — Research → Write → Score → Visuals → Publish
2. **Keyword Research Sprint** — Evaluate multiple keywords with metrics and competition data
3. **Content Refresh** — Audit and update existing content for better rankings
4. **Competitor Deep Dive** — Analyze what competitors rank for and where to differentiate
5. **Social Media Content Pack** — Generate platform-optimized visual assets

## Individual Plugins

Each tool is also available as a standalone plugin:

- `neuronwriter` — SEO content analysis and WordPress publishing
- `textfocus` — Keyword research and semantic analysis
- `markupgo` — Image/PDF generation and social asset packs
- `outscraper` — Web scraping and data enrichment
