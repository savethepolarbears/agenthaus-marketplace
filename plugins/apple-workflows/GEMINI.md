# apple-workflows

Manage Apple Notes, Reminders, and Shortcuts with AI agents via a local MCP server on macOS.

## Plugin Reference

@plugins/apple-workflows/README.md

## MCP Setup

Run `agenthaus install --target antigravity` to register the servers from `gemini-settings-snippet.json` in Gemini CLI `settings.json` and Antigravity `mcp_config.json`.
