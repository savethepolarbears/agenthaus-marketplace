# notfair-marketing

Open-source Claude Code agent skills for SEO, GEO, Google Ads, and Meta Ads. Connects to live account data via Google Ads MCP, Meta Ads MCP, Google Search Console MCP, and Google Analytics (GA4) MCP.

## Plugin Reference

@plugins/notfair-marketing/README.md

## MCP Setup

Run `agenthaus install --target antigravity` to register the servers from `gemini-settings-snippet.json` in Gemini CLI `settings.json` and Antigravity `mcp_config.json`.
