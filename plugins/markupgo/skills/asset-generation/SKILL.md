# Asset Generation with MarkupGo

## Start here

Resolve input type, dimensions, format, template variables and destination. Choose the matching image, PDF, template or transformation tool. Render one preview, inspect output dimensions and content, then batch only the approved design.

Keep credentials in environment/vault references. Verify current tool schemas before calls; examples in references are procedural guidance, not live service proof. Preserve authorization, privacy, rate limits and bounded output. Do not load every reference by default.
