# markupgo

Generate images, PDFs, and social media asset packs from HTML, URLs, Markdown, and reusable templates via MarkupGo's 16 MCP tools.

## Plugin Reference

@plugins/markupgo/README.md

## MCP Setup

Run `agenthaus install --target antigravity` to register the servers from `gemini-settings-snippet.json` in Gemini CLI `settings.json` and Antigravity `mcp_config.json`.
