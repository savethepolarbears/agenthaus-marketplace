# devops-flow

Orchestrate Cloudflare deployments, GitHub PRs, and Slack notifications.

## Plugin Reference

@plugins/devops-flow/README.md

## MCP Setup

Run `agenthaus install --target antigravity` to register the servers from `gemini-settings-snippet.json` in Gemini CLI `settings.json` and Antigravity `mcp_config.json`.

> **Note:** Hooks are Claude Code-format and are not translated to Gemini CLI or Antigravity hooks.
